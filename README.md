# Trading Journal

A Python + MySQL based Trading Journal application to record, manage, analyze and track trading performance.

## Features

* Add Trade
* View Trades
* Update Trade
* Delete Trade
* Trade Analysis
* Export Reports to Excel
* Performance Charts

## Technologies Used

* Python
* MySQL
* Pandas
* Matplotlib
* OpenPyXL

## Project Structure

* main.py
* db.py
* trade_operations.py
* view_trades.py
* update_trade.py
* delete_trade.py
* analysis.py
* reports.py
* charts.py

## How to Run

1. Clone the repository
2. Install required libraries
3. Configure MySQL database
4. Run:

```bash
python3 main.py
```
